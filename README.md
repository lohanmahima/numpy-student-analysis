# Student Performance Analysis using NumPy

A beginner-friendly data analysis project built using Python and NumPy.

## About the Project

This project analyzes student marks using NumPy arrays and basic numerical operations.

The project demonstrates how NumPy can be used to calculate statistics, filter data, identify the highest-performing student, and classify student performance.

## Technologies Used

- Python
- NumPy
- Git
- GitHub

## NumPy Concepts Used

- NumPy arrays
- 2D arrays
- Indexing and slicing
- Array shape
- Mean and median
- Standard deviation
- Sorting
- Boolean filtering
- `axis=0` and `axis=1`
- `np.argmax()`

## Features

- Calculate subject-wise averages
- Calculate student-wise averages
- Find overall average marks
- Find highest and lowest marks
- Filter students based on performance
- Calculate subject statistics
- Identify the topper
- Categorize student performance
